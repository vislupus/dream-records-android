# Changelog

All notable public releases of Dream Records are recorded here.

## [1.0.0] - 2026-11-10

### Added

- Voice recording with foreground operation and configurable silence-based auto-stop.
- Recordings grouped by night, with searchable transcripts and playback controls.
- Optional transcription integrations for Gemini, Groq Whisper, and ElevenLabs Scribe.
- Colored tags, dream calendar, and editable combined night transcripts.
- ZIP/YAML export and import with audio restoration.
- English and Bulgarian interface localization.
- Dark, portrait-oriented Jetpack Compose user interface.

### Distribution note

The initial release build is signed using the Android debug certificate. Configure a dedicated signing key before long-term production distribution.
